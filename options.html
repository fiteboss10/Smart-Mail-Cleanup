Smart Mail Cleanup — How to Use

This extension bulk-moves or deletes emails by sender domain or specific address. Scan selected folders, build rules, preview with Dry Run, then act. Your rules are stored locally in Thunderbird and never leave your computer.

📂 Step 1 — Load Folders

The Folders to Scan bar at the top loads automatically on open. On first use all folders are unchecked — you must deliberately select which ones to scan before anything else works.

  • Check Skip Trash / Junk / Sent / Drafts to exclude those folder types automatically.
  • Click Load Folders to refresh after adding accounts or creating new folders.
  • Scan Folders, Dry Run, and Run Now are disabled until at least one folder is selected.
  • Your selection is saved and restored each session.
💡 Start with just your Inbox. Add more folders once you are confident in your rules.

🔍 Step 2 — Discover Senders

Click Discover Senders then Scan Folders. The extension reads every message in your selected folders and builds a deduplicated list of sending domains.

  • Messages — total messages from that domain in the scanned folders.
  • Unique addresses — how many distinct email addresses were seen for that domain. A high count suggests using Address match for precision.
  • Match — Domain — matches any message from anyone at that domain.
  • Match — Address — shows a dropdown of every address seen, sorted by message count. Only that address is matched.
  • Age-Based — checked by default. Only matches messages older than N days. Blank uses the global default from My Rules Settings.
  • Senders already in rules show a green ✓ in rules badge. Specific addresses already in rules are marked in the address dropdown.

Use the Sort dropdown to put new senders (not yet in rules) at the top — the default after scanning. Check Include for each sender, then click ➕ Add Selected to Rules.

📋 Step 3 — My Rules

All saved rules appear here, sorted by root domain (news.example.com sorts under example). Each row:

  • On — toggle a rule on or off without deleting it.
  • Sender / Address — the domain or email address being matched. Click to edit. For address rules a dropdown of discovered addresses appears if a scan was done this session.
  • Match badge — 🌐 domain (green) or @ address (blue). Click to toggle. Switching to Address pre-fills the most common discovered address; switching back to Domain extracts the domain automatically.
  • Age-Based — only match messages older than N days. Enabled by default on new rules.
  • Age (days) — per-rule override. Blank uses the global default.
  • 📎 — tick to skip messages that have attachments even if all other rule conditions match. Uses a post-scan API call per matched message.

Global Settings:

  • Default delete age — used by any age-based rule with no per-sender override.
  • On delete — Move to Trash (recommended; recoverable), Move to Found folder (created automatically per account; good for review), or Permanently delete (irreversible).
  • Auto-run — apply all enabled rules silently each time Thunderbird starts.
  • Exclude keywords — any message whose subject contains one of these words is protected from all rules. Press Enter or comma to add. Useful for receipts, invoices, shipping notices.

Use Export JSON to back up rules and Import JSON to restore. The JSON file can be opened in any text editor for searching or manual editing.

💡 Use Found folder mode when testing new rules — review what was caught before committing to permanent deletion.

▶ Step 4 — Run

The Run tab shows enabled rules, delete mode, and folders selected. Dry Run results are cached — Run Now immediately after reuses them with no second scan.

  • 🔍 Dry Run — scans folders, applies rules, checks attachments where required, shows per-sender counts. Nothing is moved or deleted. Click any sender row to expand and see individual subjects, dates, folders, and a 💋 View button to open the message in Thunderbird.
  • ▶ Run Now — reuses cached Dry Run IDs (no rescan), shows a confirmation, then moves or deletes.

All rules are evaluated in a single folder pass — 200 rules over one folder reads each message once, not 200 times. The attachment check runs as a separate post-scan pass on matched messages only.

💡 Always expand Dry Run results and review matched messages before your first Run Now on any new rules.

⚙️ Tips & Best Practices

  • Domain matching is boundary-anchored — bank.com matches alerts@bank.com but not notbank.com.
  • Use Address match to target one sender at a domain while keeping others (e.g. delete alerts@chase.com, keep support@chase.com).
  • Use Age-Based for banks, utilities, or senders where recent messages matter but history does not.
  • The 📎 attachment filter is accurate but adds one API call per matched message. Use selectively.
  • Your rules JSON can be searched in any text editor — faster than scrolling the UI with hundreds of rules.
  • The Found folder is created automatically per account. If creation fails the run aborts — no messages are lost.
  • Clearing rules or deleting individual rows immediately updates Discover tab badges.
